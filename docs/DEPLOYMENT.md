# POLARTWIN — Free Vercel + Render Deployment

## Architecture

- **Vercel Hobby**: React/Vite 3D frontend.
- **Render Free Web Service**: Python/FastAPI backend.
- **Neon Free PostgreSQL**: persistent relational database.
- **TimescaleDB is optional**: the existing migration detects the extension and safely falls back to normal PostgreSQL.

Render's Free Postgres database expires after 30 days, so the production prototype uses an external Postgres database instead.

## Render backend

Create a Render Blueprint from the repository and deploy `render.yaml`.

The service:
- uses the `backend/` directory as its root;
- installs `requirements.txt`;
- runs migrations and the idempotent seed before starting Uvicorn;
- exposes `/health` as its health check.

Required values in Render:
`POLARTWIN_DATABASE_URL` — Neon PostgreSQL connection string using `postgresql+psycopg://...`.
`POLARTWIN_AUTH_SECRET` is generated by Render.
`POLARTWIN_CORS_ORIGINS` should contain the exact Vercel origin after the frontend is deployed.

The Render Free service sleeps after 15 minutes of inactivity, so the first request after idle can take about a minute.

## Neon

Create a free PostgreSQL project and paste its connection string into Render as `POLARTWIN_DATABASE_URL`.

For an SSL connection, append the provider's required SSL option, for example:
`?sslmode=require`.

## Vercel frontend

Import the GitHub repository into Vercel.

Use:
- Framework: Vite
- Install: `npm ci`
- Build: `npm run build`
- Output: `dist`

Set:
`VITE_API_BASE_URL=https://polartwin-api.onrender.com`

Then redeploy.

The committed `vercel.json` preserves Vite SPA routing on refresh.

## Final CORS step

Copy the exact production Vercel URL into Render:
`POLARTWIN_CORS_ORIGINS=["https://YOUR-PROJECT.vercel.app"]`

Redeploy the backend.

## Smoke tests

1. Open the Vercel URL.
2. Maitri/Bharati station selector loads.
3. Overview and assets resolve from the Render API.
4. Telemetry is returned with provenance metadata.
5. No CORS errors appear in the browser.
6. `https://polartwin-api.onrender.com/health` returns HTTP 200 and database status `ok`.

## Secrets

Never commit `POLARTWIN_DATABASE_URL`, `POLARTWIN_AUTH_SECRET`, or any other credentials.

Only `VITE_*` variables are browser-exposed.
